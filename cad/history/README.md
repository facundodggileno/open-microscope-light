# Revisión histórica OpenSCAD

Este directorio archiva las versiones efectivamente disponibles en las conversaciones y archivos originales **V0.6 a V0.20**. Cada una conserva su nombre; los ajustes iterativos también aparecen como commits independientes en main.

El diseño para construir está en **../current/microscope_led_head_v020.scad**. Las revisiones anteriores pueden contener interferencias, medidas iniciales erróneas o geometrías exploratorias y no deben usarse como modelo final sin inspeccionarlas.

No se encontraron archivos denominados V0.1–V0.5. Se conserva V0.15 porque el archivo existe, aunque en la conversación una primera exportación de ese nombre había fallado; el estado real del artefacto está representado por su contenido.
