# STL finales — V0.20

Los STL son exportaciones del archivo fuente canónico [microscope_led_head_v020.scad](../current/microscope_led_head_v020.scad).

**Cantidad a imprimir:** 1 × ring, 4 × arm, 4 × pod.

Si todavía no aparecen archivos STL binarios en esta carpeta, se generan mediante el workflow [Generate V0.20 printable STL and preview](../../.github/workflows/build-models.yml). También podés exportarlos localmente con el script [tools/export-v020-stl.sh](../../tools/export-v020-stl.sh) o desde OpenSCAD utilizando la variable **part**.

Los STL no reemplazan verificar medidas reales de tu Barlow/disipadores ni el material térmicamente adecuado.
